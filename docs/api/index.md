# API Reference

The module pages linked below are generated from the current `dmm` package
by Python's standard-library [pydoc](https://docs.python.org/3.12/library/pydoc.html)
during each MkDocs build. Each module has a native HTML page with public
signatures, docstrings, classes, constants, and links to related project modules.
Newly added modules are discovered automatically.

The `dmm._native` page documents bound C++ executors and the native Cannon
function. `dmm.execution` re-exports these classes directly. The native C++
matrix and algorithm interfaces are described in the [C++ reference](cpp.md).

Edit the source docstrings to change this reference; the generated HTML pages
are not committed. Private helpers follow pydoc's normal visibility rules.
For executable examples, use [Usage](../usage.md#python-api-examples); for the
algorithm extension contract, see [Adding an algorithm](../contribute.md).

Use each module page's **API index** link to return here. MkDocs search indexes
this module directory; use your browser's Find command within native pydoc pages.
